# 一卷西北味 1.7 素材清单

1.7 版本已将四道成品图替换为项目内统一风格的矢量插画，并接入成果展示页与最终餐桌：

- `foods/hui-lamb-noodles.svg`：羊肉臊子面
- `foods/tibetan-tsampa.svg`：糌粑
- `foods/kazakh-naren.svg`：纳仁
- `foods/uyghur-pilaf.svg`：抓饭

背景音乐使用浏览器 Web Audio 生成的无歌词轻音乐旋律，不依赖外部音频文件；后续若替换为正式音乐，需要补充音乐名称、来源、授权范围和使用期限。

正式素材接入时建议按以下目录归档：

- `backgrounds/`：首页、地图、四类制作场景横屏背景（WebP）
- `outfits/`：四民族男女服饰透明图（PNG/WebP）
- `foods/`：美食成品图（WebP）
- `ingredients/`：食材透明图（PNG/WebP）
- `audio/`：各民族/地区音乐片段（MP3/OGG）
- `patterns/`：地图纹样与 UI 装饰（SVG）

每个素材应同步记录：名称、来源、授权范围、授权期限、核验人和替代降级方案。
